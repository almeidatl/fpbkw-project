# FPBKW Scoreboard - Campeonato Paraibano de Kung Fu 🥋

## 📌 Sobre o projeto
Este projeto foi desenvolvido para a **Federação Paraibana de Kung Fu (FPBKW)** e tem como objetivo fornecer uma ferramenta simples e eficiente para o cálculo de pontuação dos competidores no **Campeonato Paraibano de Kung Fu**. A interface permite que os juízes insiram as notas atribuídas aos atletas e obtenham um resultado processado de forma justa e precisa.

## 🏗️ Estrutura do código
O código HTML e JavaScript fornecem a estrutura para um sistema de cálculo de notas baseado na seguinte lógica:

### 1️⃣ Entrada de Notas
Os usuários podem inserir cinco notas através de **inputs numéricos** na interface.

### 2️⃣ Processamento das Notas
- As cinco notas inseridas são **convertidas em números**.
- A lista de notas é **ordenada** em ordem crescente.
- Para garantir um julgamento justo, **as notas extremas** (a menor e a maior) são descartadas.
- A média final é calculada com as **três notas intermediárias**.

### 3️⃣ Exibição do Resultado
Após o cálculo, a média final do atleta é exibida na tela **com duas casas decimais**.

### 4️⃣ Função de Reset
O sistema também conta com um botão de **"Zerar"**, que limpa todas as entradas e o resultado.

## ⚡ Tecnologias utilizadas
- **HTML5** 🏗️: Estrutura da página e dos campos de entrada.
- **CSS3** 🎨: Estilização do layout (necessário adicionar `style.css`).
- **JavaScript** ⚡: Lógica de cálculo e manipulação do DOM. 

Este sistema ajuda a tornar a avaliação dos competidores mais justa, eficiente e organizada. 🚀🥋
